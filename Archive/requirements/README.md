# Archived requirements

This directory preserves superseded requirements artefacts for history and
traceability. Nothing here overrides the current baseline in
[`Requirements/`](../../Requirements/).

| Folder | Contents |
|---|---|
| [`baselines/`](baselines/) | Superseded v2.x, v3.0, v4.0.1, and v4.0.2 baseline snapshots. |
| [`change-proposals/`](change-proposals/) | Proposals already incorporated into a later baseline. |
| [`audits/`](audits/) | Point-in-time consistency and drift audits. |
| [`reference/`](reference/) | Legacy expanded requirements compilation. |

The remaining files at this level preserve the earliest v2.1 baseline and its
deviation analysis. They are retained in their original format for continuity.
