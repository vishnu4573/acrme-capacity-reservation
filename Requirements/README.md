# Requirements

This directory contains only the current requirements baseline and pending
requirements changes.

| Artifact | Status |
|---|---|
| [`acrme_requirements_baseline_v4_0_3.md`](acrme_requirements_baseline_v4_0_3.md) | Authoritative working baseline, resolved by `check_grounding.py --baseline-only`. |
| [`acrme_sku_financial_approval_baseline_change.md`](acrme_sku_financial_approval_baseline_change.md) | Open baseline-change proposal; baseline incorporation remains pending. |

The requirements baseline remains the programme source of truth. YAML
configuration records intended deployment policy but does not by itself prove
runtime enforcement or readiness.

Superseded baselines, completed change records, audits, and legacy reference
material live under [`Archive/requirements/`](../Archive/requirements/). Do not
return historical files to this active folder.
