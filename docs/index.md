# ACRME Documentation

Browse and search this local edition of the Azure Capacity Reservation &
Management Enablement documentation.

- [Requirements baseline v4.0.2](Requirements/acrme_requirements_baseline_v4_0_2.md)
  is the authoritative baseline for this edition. The v4.0.3 working draft is
  not included.
- [Functional design](Design/acrme_functional_design_document.md) and
  [technical design](Design/acrme_technical_design_document.md) are reconciliation
  drafts, not ratified specifications or evidence of runtime readiness.

The site includes the diagram sources linked from these design drafts. Deployment
configuration links point to the source repository rather than bundling the YAML
files. The full repository index remains in `docs/README.md`.
